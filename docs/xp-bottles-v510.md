# Fioles d’XP : banque et échanges

Dans l’inventaire, utiliser une fiole ouvre un choix du montant d’XP à ajouter en banque, par multiples de 100 XP. Le nombre de fioles consommées est affiché avant confirmation. Le bouton « Tout utiliser » est limité à 100 fioles par opération. Les fioles sont consommées et la réserve créditée dans la même transaction. Annuler ne consomme rien.

Les fioles non utilisées peuvent être proposées ou demandées dans la bourse d’échanges, ainsi que dans les échanges ciblés entre joueurs. Les fioles proposées sont réservées dès la publication ; l’annulation ou l’expiration restitue le stock. L’XP déjà mise en banque reste liée au compte et ne devient pas échangeable.

La migration étend les contraintes des offres publiques existantes pour accepter le type xp_bottle. Les quantités restent entières et sont vérifiées côté serveur.
