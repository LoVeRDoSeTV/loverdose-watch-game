LoVeRDoSe Watch Game - V99 optimisation frontend + bande passante

Base : V98 optimisée WebP.

NOUVEAUTÉS V99
- index.html séparé en index.html + styles.css + app.js + auth-fallback.js ;
- le script de secours d’authentification reste séparé pour continuer à fonctionner si le script principal rencontre une erreur ;
- deux anciennes images PNG encore intégrées en base64 dans le CSS ont été supprimées ;
- ces visuels utilisent désormais assets/egg-premium.webp et assets/fragment-premium.webp ;
- compression HTTP activée avec le middleware compression (gzip) ;
- CSS/JS mis en cache 7 jours avec versionnement ?v=99 ;
- images WebP/SVG conservées avec cache 24 h + stale-while-revalidate ;
- index.html reste en no-cache pour voir les nouveaux déploiements immédiatement.

IMPORTANT
